本目录是上游当前源码快照，不是开发机全局 Skill 的软链接。随包保留 Deck 生产所需的 `assets/`、`references/`、`scripts/` 和示例；不包含 `.env.example`、`node_modules/` 或 `.git/`。本地适配只做以下事情：

1. `SKILL.md` 是短的项目执行入口；原通用设计说明转为 `UPSTREAM.md` 按需参考，不以三版默认、模型降级或通用角色轮换覆盖项目规则。
2. 删除独立的凭据配置文件及环境变量值示例，改掉开发机家目录、下载目录和临时目录示例，避免把本机路径带入可移交工作包。React 扩展参考移除浏览器填写密钥直调模型的示例，保留模拟数据与受控后端接入说明；只解释真实协议字段（如 `x-api-key`），不修改协议名，不授权外部调用。
3. 把一个示例文件名中的敏感词替换成等义中文名；不改变示例逻辑。
4. 由本工作包的 `html-deck` 和主控规则负责策略内容、版本绑定、独立检核、策略师确认和客户确认；Huashu 不拥有这些权限。
5. 正式视觉通过 `visual_style` 接入现有单文件 HTML：样式、内容及来源一同登记、冻结和检核。工作包的 `scripts/deck_export.py` 负责宿主依赖解析、原生页面 PDF 导出和来源回读；这些适配脚本不冒称上游原有能力。
6. 2026-09-21 增加工作包 `page_plan`：屏幕内容与完整讲者稿分开，支持有原文引用的表格/图表和有指纹的本地静态图片；素材和页面进入同一正式版本及独立逐页检核。该适配由工作包脚本实现，不声称上游直接提供这套审批机制。

正式演示稿为已登记的离线 HTML。确认后可导出绑定来源的 PDF，导出状态仍是待视觉检核，不自动获得业务批准。上游自由布局多文件和 PPTX 两条路线作为扩展参考保留，未自动接入原生版本/审核。云端视频审阅、动画后端和外部账号不在默认提案流程中调用。工作包不依赖开发机的全局 Skill，不携带 `node_modules`；不静默自更新。
