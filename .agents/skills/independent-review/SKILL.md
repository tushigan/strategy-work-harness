# 中立检核

检核者必须读取原始任务、验收标准、来源证据、上游版本和实际产出。报告写明产出版本、检查范围、结论、证据定位和未覆盖项。

作者与检核者必须是不同执行实例。检核者不直接修改被检产出后再批准自己。红灯表示明确违反策略或严重误读，黄灯表示可商榷或需要补证据，绿灯表示在检查范围内成立；个人审美偏好不能直接判红灯。

最多自动修订两轮；第二轮后仍未通过就保留各版本和争议，交策略师决定。

合同、排期和 Excel 的实际报告格式及命令见 `运行环境与命令.md`。报告必须绑定当前版本、原件、上游和实际文件；Excel 还要评估全部渲染图，并写清可读性问题或未验证限制。
独立业务检核不是代码审查；自动化测试中的模拟确认也不是策略师真的批准。

## 简报、研究与品牌屋

主控用 `phase3.py review-sources` 生成必要文件列表。检核实例完整读取列表内 JSON、Markdown、任务合同、上游原文及反馈；长资料分批读取，不接受作者摘要替代。列表和指纹只能核验覆盖，不能替代内容判断。

正式产出包括简报、研究准备、证据、分析、品牌屋、独立推导及总控 `summary`。按上游顺序检核，通过后主控登记；依赖未通过不能给下游放行。作者实例必须为实际执行者，不通过换角色名称回避自审。

报告字段及命令见 `策略与品牌屋运行说明.md`：精确 `target`、真实 `reviewer_instance`、`status`、章节 `scope`、`assessment` 五项判断、`findings`、`uncovered`、实际读过的 `checked_sources`。真实 Agent 对合成资料的判断为 `simulation:false`；只有程序模拟报告为 true。合成案例本身仍需明确标注，人工测试确认必须另标模拟。

状态仅为 `passed/passed_with_yellow/returned/insufficient_evidence`。有黄灯必须附黄灯通过，有红灯、关键原文未读或范围未覆盖不能通过。重点检查事实与意见是否混用、反证是否保留、消费者利益是否有推导、使命愿景价值观是否各自成立，以及现有能力与待建设项是否分开；不要求模仿总监措辞。

每次修订重新检核，最多两轮自动业务修订，人工反馈次数另记。上游变化、旧版批准或作者自审不能放行；额外轮次必须有明确决定且累计保留原轮次。检核者只写报告，不改稿、不确认、不更新项目总状态。

## 跨阶段与总控

总入口为 `python scripts/review_gate.py inspect --workspace .`，复用各阶段实际门禁，不把一次总检查当作新的通过报告。来源资料不是可批准的正式产出。

项目汇总、外部任务交付登记、结项报告使用 `control_artifacts.py`。主控先 `sources` 提供完整来源及章节，检核者写与提案检核同类的五项实质判断、红黄绿意见和未覆盖清单，`target` 使用 `control` 完整引用。任何历版作者都不能检核该产出，不能将作者改名替代 fresh 实例。

结项报告须检查每个合同列项对应的实际交付、任务、报告、策略师和客户确认原文；有未交付产品战略或未客户确认就不能结束。检核只判断记录与业务依据，不伪造客户身份或同意。

## 提案、演示稿和设计返回稿

逐字稿、HTML 品牌屋和演示稿各自独立检核，不能共享一份通过结果。按相应 Skill 取得全部原文、精确上游、实际文件与必要的逐页视觉证据。

设计返回稿先由 design-expression-reviewer 提出诊断候选；你须是不同的 fresh independent-reviewer，完整读取原件、当前简报、来源、逐页画面及候选诊断，重新作判断，而不是给诊断自报盖章。最终报告使用 design-expression-review 的现有 design-review 格式，写你的真实执行实例，由总控回读登记。此处不增加审批接口，也不能把通过当客户批准。

检核报告是检核证据，不递归要求报告检核自身。无法使用真正独立实例时明确待检，不以作者改名代替。

## 执行契约

- **触发**：任何正式候选产出准备进入策略师确认、客户交付、下一阶段生成或结项时触发；普通草稿不强行登记正式报告。
- **开始**：列出本次完整检查范围、原始依据、上游版本、实际文件和独立性排除项；缺一项先标资料不足。
- **产出**：报告逐项写结论、证据定位、未覆盖项、状态和下一动作。`passed`、`passed_with_yellow`、`returned`、`insufficient_evidence` 只根据实际证据选择。
- **停止**：原文未读全、实际画面未看、版本或指纹不一致、作者参与检核、红灯或关键范围未覆盖时不能通过。
- **交接**：报告交主控回读；主控再请策略师确认或按报告回改，不由检核者直接改稿或更新公共状态。
