# 可编辑品牌屋

## 先核对

读取 `AGENTS.md`、`project/state.json`、本任务的正文、上游版本与实际独立检核。已有 HTML 先运行 `python scripts/brand_house.py scan --workspace .`，再读取完整实际文件和来源，不从聊天摘要或缓存猜当前稿。

正文、原始来源、缺口、反证和假设必须完整保留。所有11章、章节标题、支持项、缺口与思考问题都映射；遇到新的正文结构先补明确映射，不能默默漏掉。空白模板没有客户归属，不能直接充当已确认品牌屋。

## 生成和编辑

- 使用 `python scripts/brand_house.py generate --workspace . --task <task_id> --author <真实执行实例>`。输出为 `project/outputs/brand-house/<task_id>/brand-house.html`，一个任务一个主文件，已有文件不得覆盖。生成中断按相同任务及作者恢复。
- 文件直接在本地浏览器打开。模型上的标题、正文和标签可编辑；文字与版式窗口调整字体、字号、字重、颜色、对齐、行高及有限布局。字号10-48，字重400-800白名单；不允许任意定位把正文压住。
- 每次显式保存追加完整快照；查看历史不修改当前稿。恢复生成新版本，保留全部后史，不恢复旧批准。自动摘要不代替策略师的变更原因。
- “保存原文件”须选择本文件授权；身份、生成依据或外部字节不同则停止覆盖。只有关闭流后实际文件回读一致才报成功。原文件写回是否可用以实际浏览器和授权为准。
- “导出HTML”是完整副本下载，不是原文件更新。超限时只导出已有快照，未保存稿另作“草稿备份”。草稿JSON保留全部历史、未保存内容和冲突原文，不能作为已确认业务稿。
- 缓存只是辅助。草稿恢复须明确选择，不能自动覆盖文件当前版；缓存清空后，已保存历史仍在同一HTML中。冲突保留双方，交策略师和Agent核对，不按时间默默覆盖。

## 回读与下游

使用 `inspect --task <task_id>` 回读实际 HTML。内容变化先标记正文和递归下游待对齐；仅字体或布局变化记录无正文变更的理由，不机械重写策略。没有实际逐字稿/PPT就不虚构产物或完成状态。

正文同步必须有策略师真实决定，绑定当前 HTML 的文档ID、版本、字节指纹以及正文版本。命令为 `sync-body --task <task_id> --author <真实执行实例> --decision <项目内决定JSON>`；格式见 `品牌屋HTML运行说明.md`。不可自己捏造确认；仅明确的隔离 `test_mode` 案例允许模拟。已有授权改变了对象或版本就不能直接复用。

先完成inspect，再从 `project/records/phase4-html.json` 的 `documents[task_id].document_id` 取得文档ID，目标和正文引用用本次inspect的 `target`、`synced_body`。待对齐时review被阻断是正常保护，不要求先通过它才准备同步决定。

同步会复用策略正文的修订、来源及授权记录；不会直接覆盖原始正文。若正文和HTML都各自改变，保存双方，先确认合并范围。下游改稿仍要按原任务权限和检核流程完成。

## 独立检核

`review --task <task_id>` 给出当前版本和完整必要来源。显式交给另一 fresh 实例，核对内容对应、实际显示、历史、保存边界和未覆盖环境。作者不能改个角色名自审；代码或脚本成功不等于业务检核。

报告放入当前工作包，以 `review --task <task_id> --report <报告相对路径>` 登记，再用 `gate --task <task_id>` 核对。当前HTML、新正文或上游改变后，旧报告不能放行；正式汇总也必须独立检核。有红灯或未覆盖必验范围时不能强行通过。

## 执行契约

- **触发**：已有有效品牌屋需要生成或修改可编辑 HTML，或策略师要求查看历史、保存、恢复、判断正文影响时启动。
- **开始**：先扫描实际 HTML，再回读当前正文、来源、上游版本、历史和检核报告；先区分正文变化、样式变化、未保存草稿和文件冲突。
- **产出**：单一 HTML 当前稿、文件内历史版本、人工修改记录、实际回读结果和影响判断；内容变化必须列出需要重新检核或重新确认的下游。
- **停止**：对象身份、授权、当前版本或文件回读不一致，或 HTML 与正文同时修改但合并范围不清时，保留双方并停止覆盖；不把浏览器下载或缓存当作原文件保存。
- **交接**：正文同步必须回到品牌屋修订流程并由策略师作决定；逐字稿或 PPT 只能在正文版本重新检核、确认后生成，不能从 HTML 草稿直接下推。

## 约束

这是Codex项目工作包中的交付物，不是另一个项目管理网站。不调用云端写入、不生成逐字稿/PPT、不实施设计稿检核。HTML导入只解析数据，不执行外来脚本；来源和版本容器不能由网页编辑器修改。不要声称能防御拥有本地文件写权限的恶意修改者。

本模块仅面向运行说明中的 Mac 浏览器组合。保存须得到文件授权并实际写回，再回读文件内版本和历史；下载或浏览器缓存不能当成原文件已保存。HTML 技术检查不替正文策略确认或 HTML 业务检核，未通过的报告保留；未测电脑和浏览器不能声称可用。
