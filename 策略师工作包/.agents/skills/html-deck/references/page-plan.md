# 页级方案

由 Agent 完整阅读已确认逐字稿后编写，不要求策略师填表或 JSON。禁止用固定字数截断代替内容设计。每页先决定听众需要理解的一件事，再选择要点、对照表、图表或图片。

生成请求中的 `page_plan` 是 `{script_ref, pages}`；`script_ref` 必须与请求的 `script` 完全一致。缺方案不生成正式稿。

每页必填：
- `kind`：`cover/points/table/chart/image`。第一张是唯一封面，总计 2-80 页。
- `title`：不超过100字，封面必须与逐字稿标题一致；其他页允许忠实概括。
- `section_id`：封面为 `null`，其余为实际章节编号；全部章节至少覆盖一次。
- `bullets`：1-4条，每条最多120字。写画面用语，不照搬“各位，接下来我们”等口语；保留假设、时间、范围等重要限定。
- `citations`：`[{section_id,field,quote}]`。`quote` 必须原样出现在对应字段；正文页至少引用本章节的 `spoken_text`，不能只引用标题。封面可引用头部的 `title/purpose`，章节可引用 `title/spoken_text/transition`。

程序自动将章节 `spoken_text` 和 `transition` 全文存入该页的讲者稿；画面不需要容纳全文。跨页重复讲者稿是定位辅助，不代表现场必须重复朗读。跨章节论据可加多条 citations。

按页面类型增加一项：
- `table:{columns:[列名...],rows:[[单元格...],...]}`：2-4列、1-6行，单元格最多100字。适合竞争对照、主张/证据、原方案/建议；不是把长段落塞表格。
- `chart:{unit:"样本数",series:[{label:"甲",value:20,citation:0},...]}`：1-8个非负有限值，统一零基线横条图。每项数值必须存在于所指 citation 的原文，标签/单位/样本条件由独立检核核对。不能把提及某数字当成因果、占比或市场代表性证明；复杂统计需先回逐字稿明确计算口径，不由视觉作者计算造数。
- `image:{path:"project/inputs/图片.png",sha256:"实际指纹",alt:"图片内容",caption:"用途及限制"}`：只收当前项目的静态 PNG/JPEG/WebP，单张不超过10 MiB、4000万像素。说明来源及使用授权，合成图片不得当成调研证据。原件内嵌离线 HTML，同时冻结快照；候选随后变化不会改变已登记版本。

所有画面数字必须出现在所引用原文中。这只是防止补造数字的底线，不证明语义准确。不得用颜色、比例、照片或删词改变原文判断。原始 HTML、脚本、外链媒体、SVG 和动画图片不能作为图片字段输入。

示例片段（必须替换成实际稿件及指纹，不能直接提交）：

```json
{
  "kind":"points", "title":"差异化仍需消费者验证", "section_id":"S2",
  "bullets":["内部能力已确认，但尚不能等同于消费者偏好"],
  "citations":[{"section_id":"S2","field":"spoken_text","quote":"逐字稿中实际存在的完整依据"}]
}
```

## 检核和回改

`deck-sources` 返回方案、全部上游及冻结素材。新版报告 scope 须含 `content_fidelity`；每页 visual_evidence 除画面证据外还须写 `content_fidelity` 和 `media_observation` 两段实际判断，无媒体也说明。独立实例核对每页结论、范围、因果、图表单位/数值/比例、图片用途及文字可读性。机器找到引文不等于提炼正确，作者不能自审。

只改画面概括或排版且不改变策略意思，可修订 page_plan，新建演示稿版本并重新检核、确认；若要改论断、证据、听众、目的或逐字稿正文，先回到逐字稿。浏览器文字编辑仍仅是草稿，必须回传 Agent，不能继承旧批准。上游变化后重做相关页级方案，保留旧版。
