# 按范围补录与核验资料

这是研究资料入口，不修改合同识别规则。PDF 含图片、表格含公式等提取疑点继续保留；不把 `extraction_complete` 改成 true。一次核验一页 PDF 或一个表格单元格矩形范围，只有核验范围内的转录可进入正式证据。

## 策略师只需说明实际做过的事

例如：“我核对了资料第 1 页，右上角只有装饰标识，正文逐字对应如下……核验人是某某，其他页还没核对。”Agent 负责保存转录、查当前版本并调用命令；不要求用户写 JSON、查编号或填写指纹。没有实际看过原件，不能登记核验完成；不能把提供者姓名填成做过核验的人。

1. 用 `source` 按既有方式登记原件；出现疑点时先保留未核验状态。
2. 用下面的只读命令回读归档原件、提取记录、当前版本与指纹。实际查看原件指定页或单元格，不能只读提取结果。
3. 将该范围的可靠转录保存为 UTF-8 TXT 或 Markdown，保留数字、单位、限定语及不确定内容。表格多格范围逐格标明地址；不能把公式当作执行结果，涉及结果时在核验动作中说明如何核对。
4. Agent 代填当前版本和两个指纹，按真实身份、理由和实际动作登记。转录的真实性仍由核验人负责，程序不证明陈述本身为真。

```bash
python scripts/phase3.py source-status --workspace . --key SRC-001
python scripts/phase3.py source-verify --workspace . --key SRC-001 \
  --version 1 --sha256 <当前提取记录指纹> --original-sha256 <归档原件指纹> \
  --location '第1页' --input <转录文本文件> \
  --verified-by <实际核验人> --actor <实际登记者> \
  --reason '本页有装饰图片，需核对文字提取范围' \
  --verification-action '实际查看第1页，逐段对照正文，确认图片仅为标识；只核验本页'
```

表格定位使用 `--location "'Sheet'!A2:B2"`；单格可写 `"'Sheet'!B2"`，回读后使用程序返回的标准定位。一次不接受全表通配符或不存在的页/表/格；PDF 多页逐页登记。Sheet 名中的单引号按表格惯例写两次。

## 使用范围与版本

- `source-status` 返回完整来源内容、提取疑点、核验记录和 `usable_locations`。未核验来源不能因为有人说“整体没问题”就放行。
- 补录保留原件及其指纹、核验前数据版本及指纹、转录文件及指纹、具体定位、核验人、登记者、理由、动作和登记时间。
- 有核验记录的来源只接受列表中**完全相同的核验范围**，引文必须来自该范围转录。不能把 A2:B2 的核验扩大到整行，不能从别页或未核验格取句子。需要更细定位时另行核验该范围，不自动拆分或拼接转录。
- 同页或重叠单元格重新核验会替换旧范围的有效记录，旧记录保留在旧版。被替换范围中本次未核验的部分重新不可用；其他不重叠已核验范围保留。
- 每次新增或修改核验生成来源新版本；旧证据稿、分析稿和其报告不再有效。主控按既有授权对齐相关产出，再安排新独立检核，不改旧报告目标冒充通过。
- 原件、提取快照、核验基础记录或转录被修改/丢失均拒绝使用。登记新原件从未核验状态开始，不继承旧范围。重复登记同一原件和元数据不撤销已有核验。
- `method_reference` 仍只能借鉴方法；即使转录核验完成也不能成为本项目事实证据。

核验没有消除来源原有的缺页、抽样、时效、主观意见等限制。只能证明指定范围的定位与转录有记录，不能据此说全份资料完整、公式已由程序计算、市场已经验证或客户已批准。本次不增加自动 OCR、音频转写或 DOCX 读取能力。
