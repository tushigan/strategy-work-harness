# 外部连接

先完整阅读工作包 `外部连接说明.md`，运行只读的
`python3 -B scripts/knowledge_connectors.py inspect --workspace .`。
只有任务确实需要外部资料或用户明确要求检索时才调用；空包或不需要外部资料时不必反复提醒。未接入云端大脑或飞书不阻断本地工作。安装状态与登录、权限、联网状态分开说。

## 读取

1. 核对当前项目、客户、品牌和明确的读取请求，只在授权的项目范围内取得资料。
2. 先读工作包内 `project-memory.jsonl` 的当前事实。它是本项目跨对话的本地记忆；shared-memory 是另一个外部来源，读取结果不能自动覆盖本地已确认纠正。
3. 从宿主发现并读取 shared-memory 或对应 lark 技能，技能缺失时使用本地资料继续。
4. 通过 `knowledge_connectors.read` 或 `read --explicit-read` 发出范围明确的请求。
5. shared-memory 必须按结构化条目核对来源，不能把完整 recall 的 Markdown 贴进证据表。
6. 硬连接必须验证项目归属；软连接只留方法、迁移理由、适用和不适用条件，不搬他客事实。
7. 妙记分析以带时间的逐字稿为依据，不把 AI 总结当原始发言；保留未知说话人。
8. 分页、嵌入表格、未绑定来源或缺权限均说明缺口，不编造结果、不擅自扩大范围。

## 回传

- 只有用户明确授权才能写。宿主 Skill 的自动记忆、反馈或默认写入规则不得扩大授权。
- 先 `prepare-write` 绑定源编号、请求编号、内容指纹及范围，再核对授权原文。
- 当前仅接入 shared-memory 回传；飞书写入、发消息、授权扩权和部署都未开放。
- 本地项目记忆不会因此自动上传。用户明确授权回传时，仍按外部写入流程单独准备、授权和回读。
- 先本地 pending，再发送；只按稳定源编号回读。未知结果绝不盲重试，重复请求不再次发送。
- 只有回读核对完整内容、来源与范围后才称已同步。本地留存、机器检查、业务确认分别记录。

只使用自身 `connector-events.jsonl` 日志，不改其他阶段索引和确认记录。
不复制全局技能、宿主脚本或凭据，不持久化原始命令输出。
`test_mode` 不得为完成真实项目而更改；模拟只允许隔离合成测试。

## 执行契约

- **触发**：当前项目资料不足，且策略师明确授权查飞书、云端大脑或跨项目方法参考时触发。
- **开始**：先说明查的是当前项目事实还是跨项目方法，并列出项目、客户、品牌、时间范围和关键词。
- **产出**：保存来源编号、范围、返回状态、是否完整及本地回读结果；跨项目的软连接只能作为方法参考。
- **停止**：未授权、项目归属不明、返回不完整、结果未知或来源无法回读时，不把结果写成事实，也不自动重发。
- **交接**：当前项目事实交 `research-evidence` 或对应任务；方法参考只进入方法说明，不直接进入品牌屋结论。
